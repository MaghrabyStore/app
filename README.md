# MAGHRABY STORE — FINAL COMPLETE

نسخة Local / Offline-first مبنية على V9 التي كانت الأقرب لرضاك، مع إصلاحات واستكمال الاتفاقات فقط.

- قاعدة بيانات محلية IndexedDB ولا يوجد حذف تلقائي للمعاملات بعد سنة.
- واجهة عربية RTL بخط أوضح، واللوجو الرسمي PNG داخل public/logo.png.
- المبيعات والكاشير، السلة، الخصم العادي، طرق الدفع الثلاثة، الفواتير وإعادة الطباعة.
- المخزون: إضافة/تعديل/حذف/تعطيل، مشتريات، مرتجعات، وحركات مخزون.
- الصيانة: PS5/PS4/Xbox/دراع/يد تحكم أخرى، تاريخ ووقت الاستلام، أنواع وأسعار الصيانة، WhatsApp، QR، وحالة التسليم مع التحصيل من الكاشير.
- الدرج والمحفظة وInstaPay مع تحويلات لا تدخل كدخل/خرج، وإقفال يومي ورصيد مرحّل.
- التقارير اليومية والأسبوعية والشهرية والسنوية، مراجعة تاريخية، وتصدير عبر طباعة/حفظ PDF.
- Backup/Restore كامل ظاهر من القائمة والإعدادات؛ Restore يستبدل البيانات الحالية بعد تأكيد.
- لا توجد Discount Codes ولا صفحة حسابات عملاء. الخصم اليدوي فقط.

## تشغيل
افتح `index.html` عبر الاستضافة المحلية/مجلد المشروع أو ارفع الملفات إلى GitHub Pages. بعد التحديث على GitHub Pages اعمل Ctrl+F5 مرة واحدة إذا كان المتصفح يعرض نسخة قديمة.
